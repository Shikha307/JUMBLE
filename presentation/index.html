Jumble – Bumble for Job Hunt

  • Jumble is a swipe-based platform that gamifies the hiring process by seamlessly connecting recruiters with top candidates — reducing average application time from hours to seconds.
  • Our primary goal is to eliminate traditional recruitment friction and make finding the perfect professional match as effortless and intuitive as possible for both candidates and recruiters.

Core Components & Architecture

🐳
Microservice Dockerized Architecture
Scalable and modular containerized setup so that our services run efficiently and independently, orchestrated via Docker Compose & deployed to AWS ECS.
🧠
ML Component
An intelligent background worker that continuously analyzes candidate and job data using TF-IDF & Cosine Similarity to deliver highly accurate, personalized matches.
⚡
Redis Integration
A high-speed, in-memory data store for rapid messaging and low-latency caching between services — powering real-time match notifications and session management.
☁️
AWS Cloud Hosting
The entire application infrastructure is deployed on AWS (ECS, ECR, EC2, S3, ElastiCache, CloudFront) to guarantee high availability, performance, and global scalability.
